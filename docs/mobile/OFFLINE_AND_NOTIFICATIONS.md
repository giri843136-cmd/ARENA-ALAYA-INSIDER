# Offline + Notifications (Mobile)

Offline:
- Reading lists and saved collections fully downloadable
- Last N recommendations and search results cached
- Background sync using Expo Task Manager when back online

Notifications:
- Price drops on saved items
- New content in followed universes
- AI assistant suggestions ("We found something you might love based on your last search")
- Marketplace approvals for partners

Delivered via Expo push + native, falling back to in-app + email.
