# Mobile App Store Release Runbook

1. Bump version in apps/mobile/app.json + package.json
2. Run full test suite + performance budgets
3. Build via EAS
4. Submit to App Store Connect / Google Play
5. Update release notes with new features (voice, visual, marketplace, AI assistant)
6. Monitor crash rate and key funnels for 48h
7. Post-mortem any issues
